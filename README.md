# Campus-Notes
Campus Notes – A centralized platform for students to upload, share, search, and download academic resources. Built with React 19, TypeScript, Node.js, PostgreSQL, Tailwind CSS, and REST APIs with authentication. 
# How To Access This Website
First download node.js latest version in your system
Then open the project main file in VScode
Open terminal then write these command -
1- dir
2- cd acad-notes-vault-main 
3- npm install
4- npm run dev 
After write these command one by one in terminal we got a local host link , open this link in your browser and access the website
